# @smithgray/safekeys-cli-win32-x64

Platform binary package for the Safekeys CLI, installed automatically as an
optional dependency of **`@smithgray/safekeys-cli`** on win32/x64.

Do not install this package directly — install the meta package:

    npm i -g @smithgray/safekeys-cli

The binary it contains is verified in CI and the release is provenance-signed.
Official packages are only under **`@smithgray`**.
